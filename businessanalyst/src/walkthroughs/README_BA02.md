# BA-02 — Scheduled report & dataset subscription

**Persona:** Business Analyst (no SQL). Subscribe to a pre-built dashboard to receive it on a
schedule, or export it on demand.

## Pre-built object

AI/BI dashboard **"Enrollment by Department (BA-02)"** — deployed by the bundle, read-only over
the shared foundation. KPIs (total enrollments, distinct students, avg GPA), a top-15 department
bar chart, an enrollment-by-year trend, and a department×term detail table.

Open it:
```bash
databricks bundle summary -t dev --profile dbx_shared_demo | grep -A2 ba_enrollment
```

## Steps — subscribe (scheduled delivery)

1. Open the **Enrollment by Department (BA-02)** dashboard (URL above, or Dashboards list).
2. Click **Schedule** / **Subscribe** (top-right).
3. Set the cadence (e.g. **Weekly, Monday 8:00 AM**) and add your email (or a Slack destination).
4. **Save.** You'll now receive the dashboard as a PDF/snapshot on that schedule — no SQL, no code.

## Steps — export on demand (BA-03 overlap)

1. On any widget (or the whole dashboard), click the **⋯** menu → **Download** → **CSV** / **Excel** / **PDF**.
2. The department×term detail table is the one to export for a spreadsheet hand-off.

## Expected outcome

A recurring email/Slack subscription is registered (visible under the dashboard's schedule list),
or a file downloads immediately. Analysts each subscribe with their own address — subscriptions
are per-user, so 20 analysts don't collide.

## Notes / troubleshooting

- **Read-only & shared:** the dashboard queries the foundation, so concurrent viewing/subscribing
  is safe.
- **Subscribe button disabled:** the workspace role may lack dashboard-subscription permission — ask your admin.
- **Data:** verified live — 40 departments, 960 department×term groups, ~overall avg GPA ≈ 3.1.
- The dashboard JSON is generated by `businessanalyst/src/dashboards/build_dashboard.py` (queries
  pre-tested); regenerate + redeploy if the schema changes.
